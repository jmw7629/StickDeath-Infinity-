# Current Studio artwork color sampling

The native eyedropper reads the canonical visible artwork at the tapped pixel. It samples imported images and the same layer/brush compositor used by actual PNG export, including visibility, blend, opacity, glow and erasing. Editor grid, onion skin and selection chrome are excluded. It changes only the drawing-color setting; it does not edit document content or add undo history.

The gesture captures project, revision, frame, viewport, zoom and pan once. Unavailable starts, context changes or interruption invalidate the attempt until a new touch. Outside coordinates, missing image sources and over-limit canvases fail explicitly. The sampler supports up to 4,194,304 pixels. The preserved service/session/canvas/test foundation is unchanged from its independent gesture-correction review.

On the current source, all 17 production sampling/gesture groups pass with actual Apple rendering and the production VM/storage. Five changed app bodies with all 116 application declarations pass arm64 iOS 17 SDK typechecking; the full proposed 15-journey native UI suite typechecks. Two new files have explicit app source membership. These checks do not establish simulator or device behavior.

The proposed native journey selects blue, draws, samples white, navigates with real Hand/Zoom, samples the transformed blue artwork, draws with the sample, checks undo/redo, saves/cold reopens and decodes the actual PNG preview. It uses the current single floating toolbar and its one dismissible options popup. The Hand popup closes before canvas gestures; Zoom/Fit are reached through that popup. No secondary right toolbar returns.

The older private integration hit a full-app SDK timeout. The narrower current-source checks above completed, but this exact final integration still requires linked native compilation, actual simulator journeys and independent review before an eligible merge. Physical-device/iPad latency, interruption runtime cases and signed release remain unverified. No cloud request or external publication is part of sampling.
