# Selected audio split at the playhead

The existing Audio inspector adds **Split at playhead** beside Duplicate after. It requires an explicitly selected managed clip and an interior playhead. The ruler keeps its existing touch layout and gains a spoken playhead value plus frame-step accessibility adjustment. Clip boundaries and sub-sample fragments disable the action.

The typed operation captures project, revision, canonical selected clip and playhead. It quantizes the cut to the production mixer's 48 kHz sample grid. The right source offset preserves the original rounded source sample index plus the number of left output samples; independently subtracting floating timestamps could otherwise shift a source sample. The left identity is retained, the right identity is new, and both share the same unchanged managed audio bytes, track, gain and mute state. Existing trimmed-audio schema metadata is promoted within the same transaction. Cancellation and context checks bracket production validation and publication; one Undo restores the original clip and schema.

Local production verification: 29 AudioTimeline groups pass, including seven new split groups. Three fractional-phase cuts produce output arrays exactly equal to the unsplit decoded stereo audio. Actual save/cold reopen, format migration and Undo/Redo, source-byte equality, both cancellation points, late playhead changes, stale project/revision/selection, playback, nonfinite/endpoint/sub-sample input and the real 128-clip limit are covered. Original failures are retained: the initial implementation omitted the existing format marker; a later fixture assumed schema3 although new production documents use schema1. Both were corrected without weakening the save/history/sample assertions.

The added native journey uses a real licensed bundled sound, taps the real ruler, verifies split counts/timing and disabled start boundary, Undo/Redo, actual mixed playback and cold reopen. SDK and 40 UI-definition compilation are recorded separately. Its native runtime has not run.
