# Direct selection handles

Continuation of #154 on the existing Move tool. Explicitly selected drawings and editable text show four white resize handles and a red rotation handle. Corners resize the group uniformly around its center within 25–400%; the red handle rotates around the same center. The existing popup provides accessible Scale/Angle controls and remains the only tool-options panel. Imported-image transforms and pivot/freeform/skew controls remain unfinished.

Touch positions are converted from the canvas viewport to document coordinates before deriving a transform. Zoom changes the editor decoration and hit radius so targets remain 44 physical points, without changing document scale. Very small viewports cannot provide those targets and retain popup operation. Handles are editor overlays only; they are excluded from thumbnails and exported artwork.

Preview uses the actual typed transform executor against a disposable editor; it does not change the current document, selection, history, asset bytes or autosave. A finished drag invokes the same command on the real editor once. Layout, zoom/pan, frame, revision, tool, selection, lock/input or foreground changes invalidate the captured gesture. Interrupted or stale gestures cannot replace an intervening edit. Existing command budgets, layer locks, matrix/result bounds and cancellation checks remain authoritative. No new dependency or Xcode source membership is required.
