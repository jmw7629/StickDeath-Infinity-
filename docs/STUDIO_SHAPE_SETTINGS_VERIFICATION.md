# Studio shape settings

Rectangle and Circle use the existing tool-options popup. Shape fill toggles between None and Solid using the drawing color. Rectangle corner radius uses document pixels, from 0 to 50, bounded by half the shape's dimensions. Stroke width and opacity affect the actual shape. The primary floating toolbar and sole dismissible popup retain their layout; no secondary right toolbar is added.

Each touch captures its own immutable shape settings. Schema 5 stores an optional versioned shape descriptor on the canonical drawing element. Earlier shapes without a descriptor keep their original outline rendering. Frame clipboard, layer duplication, full-document undo/redo and the actual device store retain the descriptor. Pasting a copied styled shape after undoing its original creation restores the required schema version. Invalid metadata fails before the transaction commits.

The same typed `draw` command used by Spatter accepts an optional `shape` object on rectangle/circle strokes. For example, `{"version":1,"fillColor":"#FF0000","cornerRadius":24}` describes a filled rounded rectangle. Circle requires radius zero. Unknown nested fields and unsupported versions, colors, tools or geometry are rejected; a bad command leaves the whole batch and history unchanged. This extends the command interface, not cloud-provider availability or natural-language generation claims.

Twelve production groups pass with actual Apple rendering/media frameworks: filled/outline rectangles, elliptical fill, document-scaled rounded corners, reversed drags, bounds, opacity applied once over fill/stroke overlap, layer visibility/opacity, legacy encoding, invalid inputs, full-document history/copies, actual VM save/list/cold reopen, decoded PNG equality and actual H.264 MP4 timing/pixels. The local MP4 test measured a mean RGB difference of about 1.36 on the 0–255 scale against the canonical white-composited reference. Test image-container adaptation uses NSImage; production models, storage and rendering are compiled unchanged.
