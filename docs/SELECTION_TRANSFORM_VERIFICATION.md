# Editable selection scale and rotation

Continuation of #154. The existing Move popup provides Scale (25–400%), Angle (−180° to 180°), Apply transform and Reset values. The operation acts on explicitly selected drawings and editable text. Apply creates one reversible edit; Reset changes only the controls. Empty selection, pending input/text drafts, locked layers, invalid settings and stale or cancelled commands cannot partially change the project. Imported-image transforms and free transform handles remain unfinished, so this slice does not close #154.

Schema 11 stores an optional six-value affine transform after historical reflection and translation. Original samples, brush seeds, sparse fill spans, text content/style, stable identities, element ordering and layer relationships remain editable. Old elements omit the new value; older project readers must reject schema11. Element/frame/layer copies preserve the transform. The renderer, thumbnails and exports use the same placement. Move previews and commits compose in world coordinates; sparse-fill hit testing applies the inverse placement.

The shared typed `transformElements` command accepts a frame reference, unique explicit element IDs, scaleX/scaleY and rotation. Commands permit 10–1,000% per axis and the same angle range. At most 1,024 selected elements are addressed. Finite matrix/inverse norms, position/result bounds and existing document/render budgets are enforced before commit. No raw matrix, shell command, provider credential or publication capability is added. Eraser masks cannot be transformed through this command.
