# Native audio workspace

The Studio audio panel now combines a searchable offline sound library with four editable audio lanes, following the owner's supplied layout. The bundled starter contains 88 real CC0 sounds (1,642,169 audio bytes). Every entry retains its original publisher, creator, license URL, source/derivative hashes and 256 waveform peaks measured from actual Apple decoding. This is a starter library, not a claim that thousands of sounds are installed. Per-source credits ship with the files. Historical reference-corpus audio is excluded.

Library preview uses the actual audio decoder/player. Add and Files import share the same integrity-checked, revision-bound production command. Saved clips own immutable bytes, never picker or bundle paths. Repeated additions have distinct clip/asset identities. Selected clip movement, lane placement, source trim, volume and mute commit reversible document edits; track mute changes its canonical clips in one transaction. Schema 4 preserves trim/mute metadata and rejects silent opening by older readers. Existing schema 1–3 decoding remains supported.

The bounded offline mixer renders actual 48 kHz stereo float CAF samples with source offsets, additive lanes, clip gains and mute. One AVAudioPlayer clock drives timeline/frame display. Audition gain is reduced when needed for over-range mixes; the rendered CAF retains the actual gains. Cancellation, stale project revisions, foreground loss, decode errors, resource limits and cleanup conflicts report factual results. Unknown/replaced scratch files are preserved with descriptor-bound ownership checks.

Passed local production checks: 15 timeline groups (real VM, storage, undo, saved source bytes, decoded mixed samples, real zero-gain player), 6 catalogue groups (all 88 sounds decoded by Apple, search, corrupt and replaced resources, import SHA pin), 14 existing audio integration groups, 15 importer groups and 26 mixer groups. Their source hashes are retained privately; no mirror-model tests substitute for production code. The combined 110-file app declaration set and 13 changed Swift bodies passed the local iOS SDK check. This is not a linked iOS app or simulator pass.

The added native journey searches for Card Shuffle, adds its actual file twice, waits for real mixed playback completion, changes volume/mute, saves, cold reopens and exercises the landscape scroll. Files-picker cancellation retains its exact canvas/history assertions. Fresh linked build and all 13 actual native journeys remain required.

Known limits: the starter has 88 sounds; mix preview is bounded to 120 seconds, 128 clips and 16 source assets. Multitrack audio in MP4/GIF export is not implemented by this slice; existing animation-only MP4 remains explicit. This single-agent integration has no independent final approval and is not eligible for merge on self-review alone.
