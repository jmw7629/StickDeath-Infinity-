# Selected artwork Copy/Paste

The existing Move popup's Copy control captures the explicit drawing selection. The existing bottom Paste control inserts new editable drawings into the current frame and active layer, then selects the new drawings so they can be dragged. The primary floating toolbar and single dismissible options popup remain in place. There is no secondary right toolbar.

Copy does not change the saved document, revision, undo history or canvas status. Paste preserves drawing samples, brush seeds, shape settings, sparse fill masks, translation and reflection, gives every drawing a fresh ID, and creates one reversible document edit. Source drawings remain unchanged. Pasting uses the destination layer's appearance; it does not copy source layer opacity, blending or glow. Multiple selected layers are flattened in their original painting order into the chosen layer.

The clipboard is local to the open project and is not persisted or written to the operating-system clipboard. The latest Copy determines its contents: frame Copy retains the existing frame-paste behavior, while selection Copy changes Paste to insert drawings without adding a frame. Imported raster-image placement is not part of this drawing clipboard. The UI exposes the current clipboard kind through Paste's accessibility label and copied drawing count in the existing Move popup.

## Commands and bounds

UI and typed commands use the same production editor. `copyElements` requires an explicit frame and unique element IDs. Its receipt exposes `clipboardElementCount` and `clipboardID`, also available in the current Studio screen context. `pasteElements` requires an explicit destination frame, layer and that exact `clipboardID`. Copy and Paste are separate requests: a caller first reads the new Copy receipt, then submits Paste with its clipboard identity and current project revision. Preparing Paste and then replacing the clipboard causes a factual stale-clipboard error, even if the document revision did not change.

Typed batches stage both document and clipboard state. Failure or cancellation publishes neither partial drawings nor a replacement clipboard. Successful drawing edits share the normal full-document Undo/Redo transaction. An intervening user clipboard change is preserved rather than overwritten by an older staged command.

Copies require 1–1,024 drawings, at most 65,536 drawing points and an estimated maximum of 8 MiB including sparse fill spans. Existing per-frame and document limits still apply. Hidden, transparent and fully locked source layers cannot be copied. Paste requires an existing visible, nontransparent destination layer that accepts drawing; full and alpha locks reject it. A failed operation retains the previous clipboard and recoverable document/history.
